# Gemeinsame Installation für CLI, GUI, Auswertung und Illustrationen.
# Vollständiger Paketstand der Windows-Referenzumgebung mit Python 3.11.3.
# Die festgelegten Pakete benötigen Python >= 3.11.
#
# STARTPUNKT
# 1. Zuerst Python installieren, falls noch nicht vorhanden:
#    https://www.python.org/downloads/ oder über die Paketverwaltung des Systems.
#    Python selbst wird NICHT durch diese Datei installiert.
#    Die Befehle unten verwenden Python 3.11; andere Versionen und Systeme
#    wurden mit diesem Paketstand nicht vollständig geprüft.
#
# 2. Im Elternordner von schritt5_pipeline_automatisierung eine neue virtuelle
#    Umgebung erstellen. Existiert .venv bereits für andere Versuche,
#    einen neuen Namen verwenden und die folgenden Pfade entsprechend anpassen.
#    venv und unittest gehören zur Standardbibliothek, nicht in die Paketliste.
#    venv richtet normalerweise auch pip in der neuen Umgebung ein.
#    Fehlt unter Linux die venv-/ensurepip-Unterstützung, muss zuerst das zur
#    Python-Version passende venv-Systempaket über die Paketverwaltung installiert
#    werden. Das ist kein Paket für "pip install".
#
#    Windows / PowerShell (Python 3.11 mit Windows-Launcher vorausgesetzt):
#    py -3.11 -m venv .venv
#    .\.venv\Scripts\Activate.ps1
#
#    Linux oder macOS / Bash (Python 3.11 vorausgesetzt):
#    python3.11 -m venv .venv
#    source .venv/bin/activate
#
# 3. In der aktivierten Umgebung alle Bibliotheken installieren und prüfen:
#    python --version
#    python -m pip install --upgrade pip
#    python -m pip install -r schritt5_pipeline_automatisierung/Dokumentation/requirements.txt
#    python -m pip check
#
# Die Kommentarzeilen werden von pip ignoriert, nicht automatisch ausgeführt.
# Ist die PowerShell-Aktivierung gesperrt, für die Befehle in Schritt 3 statt
# "python" direkt .\.venv\Scripts\python.exe verwenden.
# Bereits im Schritt-5-Ordner? Dann im Installationsbefehl den Präfix
# "schritt5_pipeline_automatisierung/" weglassen.
